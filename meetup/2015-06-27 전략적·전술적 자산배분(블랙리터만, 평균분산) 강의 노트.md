# 전략적·전술적 자산배분(블랙리터만, 평균분산) 강의 노트
*작성 2015-06-27 · 수정 2015-06-27*

강의 : 자산배분  

전략적 자산배분 ~ 국내 주식, 국내 채권, 해외 주식, 해외 채권, 원자재, 현금 등 큰 구분  
f(블랙리터만 예상수익률, 블락빌딩(팩터애널리시스) 예상수익률, VCV 매트릭스) => mean-variance portfolio with target expected return  
: 과거 변동성의 롤링 검증, 미래 변동성은 과거 변동성으로 설명 가능  
 * 조건 1 가중평균 수익률 = target  
 * 조건 2 ( 수익률 x by 1 ) x [ vcv x by x] x (비중 1 by x) = minimum  

전술적 자산배분 ~ 자산별 비중의 스윙  

세부전략 ~ 각 자산 구분 별 지역(선진.이머징)/국가(미국.일본.유럽.중국..)/섹터/스타일(성장.가치.배당..)/전략(최소변동성.최대분산효과.동일가중.이익가중...)
