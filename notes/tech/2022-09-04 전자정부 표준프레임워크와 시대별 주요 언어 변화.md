# 전자정부 표준프레임워크와 시대별 주요 언어 변화
*작성 2022-09-04 · 수정 2022-09-04*

2009년부터 대한민국 정부에서 관리, 운영하고 배포하는 Java Spring Framework, JQuery 기반의 오픈소스 프레임워크(개발용 프로그램)이다.  
eGovFrame, 전자정부 프레임워크 라고도 불린다.  
삼성, LG, Naver 등에서 프레임워크 개발 및 버전 업그레이드를 진행하고 있는 것으로 알려져 있다.  
Java, JQuery 이외에도 다양한 요소를 포함하고 있으며, 대부분의 웹/모바일 서비스를 만들 수 있는 환경을 제공한다.  
https://egovframe.go.kr/home/main.do 에서 다운로드하여 이용할 수 있다.  
한계점  
우리나라 공공기관 사이트, 대기업 솔루션, SI 사업 등의 대부분이 이 프레임워크로 만들어져 있는 것으로 보이며, 이로 인해 국내 기관 및 기업은 Java 가능인력을 선호하는 것으로 보인다.  
프레임워크의 버전이 개발 기술 발전 속도를 따라잡지 못하여 다른 개발 언어 등에 비해 속도, 개발 편의성 등이 떨어진다는 평가를 받는다.  




프로그래밍 언어는 편의성, 속도, 사용자 커뮤니티, 확장성, 유지보수 용이성 등으로 주로 선택하기 마련이다. 그로 인해 해당 시기별 시장상황 등에 의해 주로 사용되는 언어가 결정되는 것으로 보인다.  
대략적인 시기별 주요 사용언어  
~1990년대: C  
~2010년대: Java  
~2020년대: Python  
2009년 대한민국 정부에서 Java 기반 전자정부 표준프레임워크를 만들어 배포하였으며, 이로 인해 대한민국 정부기관, 대기업 솔루션 등은 대부분 Java로 작성되고 있다.  
한 번 만들어져 동작하는 프로그램은 쉽게 교체되기 어렵다.  
당시의 만들어진 프로그램 코드는 2022년 현재에도 대부분 동작하고 있을 것이며, 이에 대한 유지보수를 위해 Java 구인이 계속되고 있는 것으로 보인다.
