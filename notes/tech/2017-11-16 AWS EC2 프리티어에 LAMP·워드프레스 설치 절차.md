# AWS EC2 프리티어에 LAMP·워드프레스 설치 절차
*작성 2017-11-16 · 수정 2017-11-17*

[아마존 AWS에서 워드프레스 세팅하기]  

클라우드 서버 제공 서비스 : aws.amazon.com > 가입 완료 (1년 FreeTier)  
서버 세팅  
EC2  
‘인스턴스’ 생성  
세부 스펙은 프리티어 가능한 것만! (OS:Ubuntu LTS 16.04)  
포트 오픈 (‘모든 TCP’)  
원격접속 인증시 필요한 pem 파일은 잊어버리면 안됨!  
인스턴스의 퍼블릭 도메인 또는 퍼블릭 IP(v4) 확인  
원격접속 세팅  
putty / puttygen 다운로드  
puttygen으로 pem 파일을 이용하여 ppk 파일 생성  
putty에서 퍼블릭 도메인 또는 퍼블릭 IP + Auth(ppk파일)을 이용하여 원격접속  
서버의 Login ID는 ‘ubuntu’  
 LAMP / Wordpress 세팅  
LAMP 설치  
sudo apt-get update  
sudo apt-get upgrade  
sudo apt-get install lamp-server^  
MySQL DB 패스워드 세팅 포함  
sudo apt-get install unzip  
설치완료.  
Wordpress 설치파일(zip) 다운로드  
zip 파일 서버 업로드  
FTP 프로그램 이용  
호스트는 퍼블릭 도메인 또는 퍼블릭 IP로  
서버의 Login ID는 ubuntu  
SFTP 프로토콜 이용, pem 또는 ppk로 인증하여 연결  
서버 위치 확인 후 파일 업로드  
아파치 웹서버 경로로 zip 파일을 압축 풀기  
웹서버 경로로 파일을 이동하기  
putty 접속화면에서  
cd /home/ubuntu  
sudo mv wordpress-4.9-ko_KR.zip /var/www/html/  
sudo unzip wordpress-4.9-ko_KR.zip  
서버 재부팅
